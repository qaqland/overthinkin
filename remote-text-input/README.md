# remote-text-input

最小 Rust / Wayland 远程输入法。手机或另一台电脑打开网页打字，内容实时中转同步。

代码由 AI 按 [PROMPT.md](PROMPT.md) 生成，太简单所以只公开提示词，不含实现。

## 运行

需要支持 `input-method-v2` 的 Wayland 会话，例如 Sway：

```sh
cargo run --release
```

默认监听 `0.0.0.0:8080`，终端会打印访问地址。手机连同一局域网，把地址里的 IP
换成电脑 IP 后打开。电脑上选好输入区域，手机输入文字可看到预编辑，点“发送”提交。

可指定监听地址：

```sh
cargo run --release -- 127.0.0.1:9000
```

## 说明

- 只有第一个连接的会话能输入，其他会话自动排队，前一个断开后按顺序接管。
- 每次输入上限 3900 UTF-8 字节；中文和 emoji 通常占多个字节。
- 切换焦点后，旧草稿和发送会被拒绝，需要重新输入或发送。
- 只编辑本次草稿，不读取桌面已有文字，预编辑的 preedit 光标固定在末尾。

## 安全

HTTP / WebSocket 没有加密，也没有身份认证，不要在公网使用。
